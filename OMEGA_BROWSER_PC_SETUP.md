## 🚀 Usage Examples

### Basic Usage

```python
from unified_browser import OmegaPrimeEchoBrowser

# Create browser
omega = OmegaPrimeEchoBrowser()

# Create session
session = omega.create_session(
    device_type='desktop_highend',  # Gaming desktop profile
    country='US',                   # US IP geolocation
    use_proxy=False                 # Use direct connection
)

# Get driver
driver = session.browser_session.driver

# Navigate
driver.get('https://example.com')

# Do your work...

# Clean up
omega.close_session(session.session_id)
```

### "ChromeDriver not found" Error

**Option 1: Let Selenium Manager handle it (recommended)**
- Selenium 4.6+ auto-downloads ChromeDriver
- No manual installation needed

**Option 2: Manual installation**
```powershell
# Download ChromeDriver
# Visit: https://chromedriver.chromium.org/
# Place chromedriver.exe in TOOLS\anti-detect-browser\
```

### "Python package not found" Error

```powershell
# Install missing packages
pip install selenium requests colorama pillow
```

### Browser Won't Start

